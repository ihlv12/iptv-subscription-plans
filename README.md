## What does an IPTV 3 month subscription actually give you?

The main difference between TiviLive's three-month options is not the content package. It is the number of **simultaneous connections**.

That distinction matters more than it first sounds.

One connection means one stream at a time. A second connection makes sense when two screens need to play simultaneously, while three, four or five connections are aimed at households with several active screens. TiviLive specifically describes its pricing system around simultaneous connections, from one through five.

So rather than asking only “How much is an iptv 3 month subscription?”, the better question is: **How many streams will actually be running at the same time?**
